### Task 3: BatchGraph — `<foreignObject>` per node

**Files:**
- Modify: `src/lib/ui/BatchGraph.svelte`

- [ ] **Step 1: Read the file**

Run: `cat src/lib/ui/BatchGraph.svelte`

You'll see an SVG `{#each layout.nodes}` block. Each `<g>` has `role="button" tabindex="0" aria-label aria-pressed onclick onkeydown data-testid data-batch-id` — all the interactive concerns are on the SVG group.

- [ ] **Step 2: Restructure each node**

Replace the `<g …>` for each node with a structure that splits painting (SVG) from interaction (HTML button inside `<foreignObject>`). The full replacement for the `{#each layout.nodes as n (n.id)}` block is:

```svelte
  {#each layout.nodes as n (n.id)}
    {@const batch = byId.get(n.id)!}
    {@const isSelected = n.id === selectedId}
    {@const warnTitle = inconsistencyTitle(batch)}
    <g transform="translate({n.x + PAD},{n.y + PAD})">
      <foreignObject
        x={-NODE_R - 4}
        y={-NODE_R - 4}
        width={(NODE_R + 4) * 2}
        height={(NODE_R + 4) * 2}
      >
        <button
          type="button"
          aria-label="Select batch {batch.label} ({batch.status})"
          aria-pressed={isSelected}
          onclick={() => onSelect(n.id)}
          class="w-full h-full bg-transparent border-0 p-0 cursor-pointer rounded-full focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-ochre"
          data-testid="batch-node"
          data-batch-id={n.id}
        ></button>
      </foreignObject>
      {#if isSelected}
        <circle r={NODE_R + 4} fill="none" stroke="var(--color-ochre)" stroke-width="1.5" pointer-events="none" />
      {/if}
      <circle
        r={NODE_R}
        fill={fill(batch.status)}
        stroke={stroke(batch.status)}
        stroke-width="1.5"
        pointer-events="none"
      />
      <text
        x="0"
        y={LABEL_OFFSET_Y}
        text-anchor="middle"
        font-family="var(--font-sans)"
        font-size="11"
        fill="var(--color-obsidian)"
        pointer-events="none"
      >{truncate(batch.label)}<title>{batch.label}</title></text>
      {#if warnTitle}
        <text
          x={NODE_R + 4}
          y={-NODE_R + 2}
          font-size="12"
          fill="var(--color-ochre)"
          data-testid="batch-node-warning"
          pointer-events="none"
        >⚠<title>{warnTitle}</title></text>
      {/if}
    </g>
  {/each}
```

Three structural changes:
1. The `<g>` no longer has `role`, `tabindex`, `aria-*`, `onclick`, `onkeydown`, or `class="cursor-pointer"`.
2. A `<foreignObject>` wraps an HTML `<button>` covering just the circle area; that button carries all the interactive concerns.
3. The SVG decoration siblings (selected ring, main circle, label text, warning glyph) gain `pointer-events="none"` so the underlying button receives clicks regardless of stacking order.

Expected: green. The `foundation.e2e.ts` and other tests select batches via the graph; the `data-testid="batch-node"` selector now lives on the `<button>` instead of the `<g>` — Playwright finds it either way.
