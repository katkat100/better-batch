# A11y Phase 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close out the deferred polish items from the original a11y audit — drop incorrect ARIA roles on two popovers, bump `.text-placeholder` contrast and migrate hand-rolled empty states to use it, and bump remaining body-text `text-obsidian/40` sites to `/60`.

**Architecture:** Five small focused tasks. Tasks 1-3 are atomic edits; Task 4 covers seven empty-state migrations plus the utility bump; Task 5 bumps body-text contrast across ~6 files. All tasks are visual/structural changes with no new tests.

**Tech Stack:** SvelteKit 2, Svelte 5 (runes, snippets), Tailwind v4 (`@layer components`), Bun + `bun:test`, Playwright e2e.

**Spec:** [`2026-05-22-a11y-phase-3.md`](../specs/2026-05-22-a11y-phase-3.md)
